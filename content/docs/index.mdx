Use SwiftUI's native containers and modifiers directly. Your React mental model still helps, but the vocabulary moves to the container initializer and the view modifier chain.

## Start here

- [VStack and HStack](/docs/native-stacks) explains direction, alignment, justification, spacing, and `Spacer()`.
- [View modifiers](/docs/view-modifiers) covers padding, width, height, and modifier order.
- [Open the live Stack playground](/playgrounds/stack-layout) to generate native SwiftUI while you adjust the layout.
- [Custom fonts](/docs/custom-fonts) covers app-bundle registration, PostScript names, semantic tokens, and Dynamic Type.
- [Open the custom-font playground](/playgrounds/custom-font) to generate a Dynamic Type-aware typography token.

## React to SwiftUI

| React / CSS | SwiftUI |
| --- | --- |
| `flex-direction: column` | `VStack` |
| `flex-direction: row` | `HStack` |
| `align-items` | stack `alignment:` |
| `justify-content` | `Spacer()` or outer `.frame(alignment:)` |
| `gap` | stack `spacing:` |
| `width: 100%` | `.frame(maxWidth: .infinity)` |

The team-friendly default is simple: use `VStack`, `HStack`, and `ZStack` directly. Create a custom component when it represents a product concept, not when it only renames SwiftUI.
